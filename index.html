Image generation for Ideas using Batch API

                    
Submit a CSV to OpenAI's Batch API, let the job run in the background, and come back later to download the finished CSV with image paths.


                    

                        
                        
                        
No file selected

                    


                    

                        
What this module does

                        
    
                            
  • Builds a Batch API job for each eligible idea row.
    • 
                            
  • Lets you edit the image prompt before submission.
    • 
                            
  • Checks job status and creates the output CSV when the batch finishes.
    • 
                        


                        
Expected CSV Columns (Input)

                        

                            Upload the CSV produced by the Idea Generation card, or any CSV with the same shape.
                        

                        
    
                            
  • idea_id (required)
    • 
                            
  • idea_title (required)
    • 
                            
  • problem_or_opportunity (required)
    • 
                            
  • solution_details (required)
    • 
                            
  • potential_impact (required)
    • 
                            
  • status (required) - only rows with status == "ok" are submitted
    • 
                        


                        
Output CSV Columns

                        

                            The downloaded file contains all original columns plus:
                        

                        
    
                            
  • batch_job_id - local job id for this submission
    • 
                            
  • batch_status - current OpenAI batch status
    • 
                            
  • batch_request_counts - request count summary from OpenAI
    • 
                            
  • image_status - ok / skipped / error
    • 
                            
  • image_error - row-level error message, if any
    • 
                            
  • image_large_path, image_medium_path, image_small_path - storage-relative paths
    • 
                        


                        
Image Prompt Template

                        

                            Edit the prompt before submitting. Supported placeholders:
                            {{idea_title}}, {{problem_or_opportunity}}, {{solution_details}}, {{potential_impact}}
                        

                        

                            
                            
                        

                        
                        

                            
                        

                        

                            The job is submitted to OpenAI Batch API and may complete later. Enter your API key in the header controls like the other modules. Use the Refresh Status button or wait for auto-polling to update the job.
